# Backend

Бэкенд-сервис проекта **Bees-In-Kube** на FastAPI.
Отвечает за HTTP API, бизнес-логику и взаимодействие с инфраструктурой
(настройки, базы данных, внешние сервисы).

## Стек

- **Python 3.12+**
- **FastAPI** (`fastapi[standard]`) — HTTP API, OpenAPI/Swagger из коробки
- **Pydantic Settings** (`pydantic-settings`) — конфигурация из `.env`
- **uv** — управление зависимостями и виртуальным окружением
- **Ruff** — линтер и форматтер

## Структура проекта

```text
backend/
└── src/              # корень исходного кода (src-layout)
    ├── api/          # HTTP-слой: роутеры, схемы, эндпоинты
    ├── services/     # бизнес-логика, не зависящая от FastAPI
    └── infra/        # настройки, БД, клиенты внешних сервисов
```

> В `src/api/test_handler.py` и `src/services/test_service.py` лежат учебные
> примеры, показывающие, как связаны слои. Они помечены в docstring'ах:
> **удалите их при первом коммите в backend.**

## Запуск

Все команды выполняются из папки `backend/`.

```bash
# 1. Установить зависимости (создаст/обновит .venv)
uv sync

# 2. Запустить dev-сервер с авто-перезагрузкой
uv run fastapi dev src/main.py
```

Альтернативно, если окружение уже активировано:

```bash
fastapi dev src/main.py
# или
python src/main.py
```

После запуска:

- API: <http://127.0.0.1:8000/api/v1/test>
- Swagger UI: <http://127.0.0.1:8000/docs>
- ReDoc: <http://127.0.0.1:8000/redoc>

Production-запуск (без reload):

```bash
uv run uvicorn main:app --app-dir src --host 0.0.0.0 --port 8000
```

## Слои и правила

Проект разделён на слои, чтобы бизнес-логику можно было тестировать и
переиспользовать независимо от HTTP.

### `api/` — HTTP-слой

- Роутеры FastAPI, Pydantic-схемы запросов/ответов, эндпоинты.
- Хендлеры валидируют вход, вызывают сервис и формируют ответ.
- Здесь же бросается `HTTPException`, если нужен HTTP-статус.
- Бизнес-логики и прямого доступа к БД быть не должно.
- Один модуль на ресурс/фичу — хорошая отправная точка.
- Новый модуль подключается в `api/router.py` через
  `api_router.include_router(...)`; всё, что подключено к `api_router`,
  монтируется в `main.py` под префиксом `/api/v1`.

### `services/` — бизнес-логика

- Переиспользуемая логика, не зависящая от фреймворка: доменные модели,
  вычисления, оркестрация внешних API/БД.
- **Не импортирует FastAPI** (`Request`, `HTTPException`, роутеры и т. п.).
- Легко тестируется без запущенного сервера.
- Сервисы вызываются из `api/`; сами сервисы хендлеры не вызывают.

### `infra/` — инфраструктура

- Настройки приложения и всё, что связано с внешним окружением:
  конфигурация, подключение к БД, клиенты внешних сервисов, логирование.
- `settings.py` — `Settings` на базе `pydantic-settings`, читает `.env`.
- `config.py` — зарезервирован под инфраструктурные настройки/фабрики.

### `main.py` — точка входа

- Создаёт приложение через `create_app()`.
- Настраивает `lifespan` (старт/остановка приложения).
- Подключает `api_router` с префиксом `/api/v1`.
- Экспортирует модульную переменную `app` — её ищет FastAPI CLI/uvicorn.

## Конфигурация

Настройки описаны в `src/infra/settings.py` и читаются из переменных
окружения или файла `.env` в папке `backend/`.

| Переменная  | По умолчанию         | Описание                                      |
| ----------- | -------------------- | --------------------------------------------- |
| `APP_TITLE` | `Bees-In-Kube API`   | Заголовок приложения в `/docs`                |
| `APP_ENV`   | `development`        | Окружение: `development`, `production`, `test` |

Пример `.env`:

```dotenv
APP_TITLE=Bees-In-Kube API
APP_ENV=development
```

## Об `__init__.py`

Пакеты внутри `src/` не требуют файлов `__init__.py`: используются
namespace-пакеты (PEP 420). `src/` — это корень импортов, а не пакет,
поэтому импорты пишутся **без** префикса `src.`:

```python
from api.router import api_router
from infra.settings import Settings
from services.test_service import TestService
```

## Линтинг и форматирование

```bash
uv run ruff check src          # проверить
uv run ruff check --fix src    # исправить автоматически
uv run ruff format src         # отформатировать
```

Настройки Ruff находятся в `pyproject.toml`. Кириллические буквы в
комментариях/docstring'ах разрешены через `allowed-confusables`.

## Как добавить новый эндпоинт

1. Создайте сервис в `src/services/` с бизнес-логикой.
2. Создайте модуль в `src/api/` с `APIRouter`, схемами и хендлерами,
   которые вызывают сервис.
3. Подключите его роутер в `src/api/router.py`.
4. Проверьте `uv run fastapi dev src/main.py` и `/docs`.
5. Прогоните `uv run ruff check src` и `uv run ruff format src`.
